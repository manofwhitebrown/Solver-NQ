# Solver-NQ — User Guide

## 1. Get the app

**On your phone (Android APK)**
1. Open the repo on GitHub → **Actions** tab → **Android APK** → click the latest run with a green tick.
2. Scroll to **Artifacts**, download `solver-nq-debug-…`, and unzip it.
3. Open the `.apk` file on your phone. If asked, allow **Install unknown apps** for your browser or Files app (Settings → Apps → Special access → Install unknown apps).
4. Tap **Install**, then open **Solver-NQ**.

**On your laptop (web)**
Open https://manofwhitebrown.github.io/Solver-NQ/ . In Chrome or Edge, click the install icon in the address bar to use it as an app.

## 2. Add your free Gemini key
1. Go to https://aistudio.google.com and sign in with a Google account.
2. Click **Get API key** → **Create API key** → choose **Create API key in new project**.
3. Copy the key.
4. In Solver-NQ open **Settings** → **AI** and paste it into the Gemini key field, then save.

The key stays on your device. Free-tier limits apply; the app can switch to another free model if one is busy.

## 3. Ask your first question
Open **Ask**, type or paste a problem, and send. Pick a mode:
- **Answer** – a complete worked solution.
- **Learn** – step-by-step with hints, so you work it out yourself.

## 4. Scan
On **Scan**, take a photo of a printed problem. The text is read on your phone and you can fix it before sending.

## 5. Export, backup, offline
- **Export**: open an answer and use the export/share button to save a PDF or send it to another app.
- **Backup**: **Settings** → **Backup** lets you save all your data to a file and restore it later. Do this before changing phones.
- **Offline**: the app opens and your saved library, notes and Learn cards work without internet. Asking new questions needs internet.
